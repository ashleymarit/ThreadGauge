# Thread Gauge Co.

SQO house demo: a fictional thread-gauge crib. Steel panels, manila work orders, grease pencil. Not a real shop.

## Open locally

Serve the repo root (any static server):

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

Pages: `index.html` (Crib), `floor.html` (Shop floor), `tickets.html` (Work orders), `bay.html` (Bay door).
